C++ 本地判题服务 · 使用说明
================================

1. 把本压缩包解压到任意文件夹（不要放在中文路径下也行，但别放桌面以外的临时目录）。
2. 双击 start-lab.bat。
   会弹出一个黑窗口，看到「C++ 本地判题服务已启动」和编译器名字就说明成功了。
   —— 不要关这个窗口，关了服务就停了。
3. 回到网页 https://zijiashanggan.github.io/cpp-study/lab.html ，点「运行」。
   页面左上会显示「本地服务已连接」。
4. 用完直接关掉黑窗口即可。

要求
----
- 电脑上已经有 g++（任意版本，支持 C++17）或 Visual Studio（含「使用 C++ 的桌面开发」工作负载）。
- 不需要安装 Node、Python，也不需要打开 Visual Studio 界面。
- 服务只监听 127.0.0.1:8777，不对外网开放；编译产物放在系统临时目录，跑完自动删除。

连不上怎么办
------------
- 窗口里提示「端口 8777 被占用」：说明已经开着一个了，把旧窗口关掉再启动。
- 窗口里提示「没找到编译器」：装 VS 的 C++ 工作负载，或把 g++ 加进 PATH，然后重新双击。
- 网页一直显示未连接：确认黑窗口还开着；确认浏览器地址是 https://zijiashanggan.github.io/cpp-study/lab.html 。

可选：开机自动启动
------------------
把 start-lab.bat 的快捷方式放进「启动」文件夹即可（Win+R 输入 shell:startup）。
