配置只保存在这台设备的浏览器里（localStorage），不上传、不经过任何中间服务器；手机和电脑要各配一次，换设备不会跟着走。

Ollama 的 key 随便写，它不校验，填 ollama 就行。
电脑上要先允许这个网页访问本机 Ollama：
  1. 开始菜单搜「环境变量」→ 打开编辑系统环境变量 → 环境变量
  2. 在「用户变量」点新建：变量名 OLLAMA_ORIGINS，变量值 https://zijiashanggan.github.io
  3. 一路点确定；托盘图标右键 Quit Ollama，再重新打开
  4. 回到这里点保存，问一句试试
也可以在 PowerShell 里一条命令搞定： 
setx OLLAMA_ORIGINS "https://zijiashanggan.github.io"
设完必须重启 Ollama 才生效。如果还是被拦（浏览器的私有网络访问限制），不要去关浏览器安全策略，改在本机跑一个小代理，把页面请求转给 http://localhost:11434，这里 base 填代理的地址。
手机上选本机模型基本用不了。这个页面是 https，去调 http://localhost 会被浏览器当成混合内容直接拦掉。手机上请选 DeepSeek / 通义这类云端服务商，填你的云端 key。
